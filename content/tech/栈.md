## 1. 有效括号

题目：给定一个只包含几种括号的字符串，判断每个括号是否都能正确匹配。

> https://neetcode.io/problems/validate-parentheses

思路 1：用数组和索引模拟栈，利用先进后出的特性。遇到左括号入栈，遇到右括号时出栈并比较。Python 中数组索引 `-1` 表示最后一个元素，用起来比较方便。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 2. 最小栈

题目：实现一个最小栈，要求所有操作都是 O(1)，并支持 `getMin()` 获取栈中的最小值。

> https://neetcode.io/problems/minimum-stack

思路 1：双栈。一个栈正常存元素，另一个栈同步存当前最小值。入栈时和最小值栈的栈顶比较，存入较小值；弹出时两个栈同时弹出；获取最小值时读取第二个栈的栈顶。

- 时间复杂度：O(1)
- 空间复杂度：O(n)

思路 2：单栈。第一个值入栈时，把最小值设为当前值，并把 0 入栈。之后入栈时存当前值和最小值的差值。差值等于 0，说明当前值等于最小值；差值小于 0，说明当前值是新的最小值，可以通过 `min - current` 得到上一个最小值；差值大于 0，说明当前值不是最小值，真实值为 `min + current`。

- 时间复杂度：O(1)
- 空间复杂度：O(n)

## 3. 逆波兰表达式求值

题目：给定一个符合逆波兰表达式的字符串数组，计算表达式结果。

> https://neetcode.io/problems/evaluate-reverse-polish-notation

思路 1：用栈实现。遇到数字就压栈，遇到运算符就弹出两个数字计算，再把结果压回栈。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

思路 2：递归 DFS。从后往前遍历，遇到数字就返回，遇到运算符就继续向前取两个元素。如果某个元素仍然是运算符，就递归求值。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 4. 生成括号

题目：给定整数 `n`，表示 `n` 对括号，返回所有合法的括号序列。

> https://neetcode.io/problems/generate-parentheses

思路 1：递归遍历加剪枝。记录左括号和右括号数量。如果 `left = right = n`，说明当前序列合法；如果右括号数量大于左括号数量，直接剪枝。

- 时间复杂度：O(4^n / sqrt(n))
- 空间复杂度：O(n)

思路 2：动态规划。一对括号的所有情况可以推到两对括号，再继续推到 `n` 对。结构可以看成 `(left) right`，其中 `left + right = n - 1`。

- 时间复杂度：O(4^n / sqrt(n))
- 空间复杂度：O(n)

## 5. 每日温度

题目：给定每日温度数组，返回每个索引未来需要等待多少天才会出现更高温度。如果没有更高温度，则为 0。

示例：

- Input: `temperatures = [30,38,30,36,35,40,28]`
- Output: `[1,4,1,2,1,0,0]`

> https://neetcode.io/problems/daily-temperatures

思路 1：用栈保存温度和索引。遍历当前温度时，如果当前值不高于栈顶，压栈；如果当前值更高，就持续出栈并计算等待天数，直到栈顶温度更高或栈为空，再把当前值压栈。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

思路 2：动态规划，从后往前比较。可以借助已有的 output 做跳跃。比如示例中，如果第一个值是 39，和第二个元素 38 比较后，可以直接跳到索引 +4，再和 40 比较。平均下来每个元素访问次数有限。

- 时间复杂度：O(n)，极端情况下 O(n * n)
- 空间复杂度：O(1)

## 6. 车队

题目：单行道上有 `n` 辆车，一个数组表示位置，另一个数组表示速度。计算到达终点 `target` 时会形成多少个车队。后车追上前车后不能超过前车。

示例：

- Input: `target = 10`, `position = [4,1,0,7]`, `speed = [2,2,1,1]`
- Output: `3`

> https://neetcode.io/problems/car-fleet

思路 1：先根据位置和速度组成元组，并按位置排序。遍历时计算每辆车到终点所需时间。假设前车时间为 `x`，后车如果时间小于 `x`，就能追上前车并形成同一车队；直到出现时间大于 `x` 的车，才形成新的车队。可以用栈处理，也可以直接迭代。后车时间小于前车时，要么共同到达终点，要么被前车阻塞。

- 时间复杂度：O(n * log n)，主要来自排序。
- 空间复杂度：O(n)

## 7. 柱状图中最大的矩形

题目：给定一个直方图数组，每个值表示高度，宽度为 1，计算最大矩形面积。

示例：

- Input: `heights = [7,1,7,2,2,4]`
- Output: `8`

> https://neetcode.io/problems/largest-rectangle-in-histogram

思路 1：建立两个数组和一个栈。一个数组从左往右，记录当前位置左边第一个比它低的索引；另一个数组从右往左，记录右边第一个比它低的索引。高的元素出栈，因为向右走时它不可能越过当前元素形成更大的边界。最后用当前高度乘以左右边界范围，更新最大面积。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

思路 2：只用一个单调递增栈。栈中记录索引，从左往右遍历。当前高度小于栈顶高度时，持续出栈并计算以出栈高度为高的矩形面积。中间出栈几次，宽度也会随索引一起变化。遍历结束后，如果栈中还有元素，需要再统一计算一次。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 总结

- 栈的核心是先进后出。
- 单调栈通过入栈维持递增或递减，在出栈时计算局部最优。
- 如果一个方向不好处理，可以考虑左右两个方向分别计算。
