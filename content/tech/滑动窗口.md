## 1. 买卖股票的最佳时机

题目：给定一个数组表示每天的价格，选择一个买入点和一个卖出点，让利润最大。卖出点必须在买入点之后。

示例：

- Input: `prices = [10,1,5,6,7,1]`
- Output: `6`
- 第 2 天以 1 买入，第 5 天以 7 卖出。

> https://neetcode.io/problems/buy-and-sell-crypto

思路 1：双指针，且两个指针一前一后。因为卖出点索引一定大于买入点，所以持续更新买入点。遇到新的价格低于历史买入点时，把买入点更新为当前位置，卖出点重置为买入点后一位；否则计算当前利润并更新最大值。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

思路 2：动态规划。`dp[i]` 表示前 `i` 天能获得的最大利润。状态转移可以写成：`dp[i] = max(dp[i-1], price[i] - minPrice)`。遍历时同时维护当前已知最小价格和最大利润。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 2. 无重复字符的最长子串

题目：寻找字符串中不包含重复字符的最长子串，返回长度。

示例：

- Input: `s = "zxyzxyz"`
- Output: `3`
- `zxy` 和 `xyz` 长度都为 3。

> https://neetcode.io/problems/longest-substring-without-duplicates

思路 1：前后指针加 `HashMap<value, index>`。右指针向前移动，检查当前字符是否已经出现。如果没有出现，记录位置并继续。如果出现过，就记录当前最大长度，并把左指针移动到重复字符上一次出现位置的后一位。注意左指针不能回退，所以只有当重复字符的位置大于等于左指针时才更新左指针。

- 时间复杂度：O(n)
- 空间复杂度：O(m)，`m` 是去重后的字符数。

## 3. 替换后的最长重复字符

题目：给定一个只包含大写字母的字符串和整数 `k`，可以替换任意 `k` 个字符，找出替换后只包含同一字符的最长子串长度。

示例：

- Input: `s = "XYYX"`, `k = 2`
- Output: `4`
- 把 `X` 替换成 `Y`，或把 `Y` 替换成 `X`，都可以得到长度 4。

> https://neetcode.io/problems/longest-repeating-substring-with-replacement

思路 1：前后滑动指针。先找出字符串中所有不同字符，再对每个字符单独应用滑动窗口。右指针移动时，如果遇到目标字符就计数加一。若窗口长度减去目标字符数量不超过 `k`，继续扩展；否则移动左指针，并在左指针离开目标字符时更新计数。

- 时间复杂度：O(n)
- 空间复杂度：O(m)，`m` 为去重后的字符数。

## 4. 字符串排列

题目：给定两个小写字符串 `s1`、`s2`，如果 `s1` 的任意排列作为 `s2` 的子串存在，则返回 `true`。

示例：

- Input: `s1 = "abc"`, `s2 = "lecabee"`
- Output: `true`，`cab` 排列后等于 `abc`。
- Input: `s1 = "abc"`, `s2 = "lecaabee"`
- Output: `false`

> https://neetcode.io/problems/permutation-string

思路 1：先建立 `HashMap<s1_value, count>`。遍历 `s2` 时右指针向前走，对应计数减一。如果某个计数小于 0，说明当前窗口不合适，左指针右移并把对应计数加回来。直到窗口长度等于 `len(s1)`，说明找到了一个排列。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 5. 最小覆盖子串

题目：给定两个字符串 `s1`、`s2`，从 `s1` 中找出包含 `s2` 去重后所有元素的最短子串。

> https://neetcode.io/problems/minimum-window-with-characters

思路 1：先把 `s2` 的元素保存为 set。前后指针开始滑动，直到右指针遇到 `s2` 中的元素，再开始记录窗口内容。用 `Map<value, count>` 统计当前窗口中命中的字符，当 map 长度和 `s2` 的 set 长度一致时，记录当前窗口长度和索引。之后移动左指针，并同步减少对应计数，直到窗口不再满足条件，再继续移动右指针。

- 时间复杂度：O(n)
- 空间复杂度：O(m)

## 6. 最大滑动窗口

题目：给定一个整数数组和窗口大小 `k`，窗口从左到右滑动，返回每个窗口中的最大值。

示例：

- Input: `nums = [1,2,1,0,4,2,6]`, `k = 3`
- Output: `[2,2,4,4,6]`

> https://neetcode.io/problems/sliding-window-maximum

思路 1：把 `nums` 按 `k` 个数一组分块。比如 `[1,2,1][0,4,2][6]`。从左到右计算每个位置在当前分块内的最大值，再从右到左计算一次。每个滑动窗口要么完全在一个分块内，要么跨两个分块，只需要取左右边界对应的两个最大值再比较。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

思路 2：借助双端队列。队列中保存单调递减的元素索引。遍历数组时，如果遇到更大的元素，就把队尾中比它小的元素全部移除；同时每次都要检查队首索引是否已经离开窗口。窗口形成后，队首就是当前窗口最大值。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 总结

- 滑动窗口通常用前后指针维护一个区间。
- 后指针负责扩展窗口，前指针通常在窗口不满足条件时移动。
- 字符串题里，字符种类有限时，去重字符集常常可以看作常数规模。
- 有些窗口题需要配合数据结构，把窗口内已经不可能成为答案的元素剔除掉。
- 左右两个方向的窗口信息可以结合使用。
