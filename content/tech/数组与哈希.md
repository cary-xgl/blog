## 1. 判断数组是否存在重复数字

题目：判断数组中是否存在重复数字，存在则返回 `true`，否则返回 `false`。

> https://neetcode.io/problems/duplicate-integer

思路 1：双重循环。外层遍历到 `N`，内层遍历到 `N - 1`，逐个比较。

- 时间复杂度：O(n * n)
- 空间复杂度：O(1)

思路 2：借助 `HashSet` 去重。遍历数组时，如果元素已经存在，直接返回 `true`。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

思路 3：先排序，再遍历。重复元素在排序后一定相邻。

- 时间复杂度：O(n * log n)
- 空间复杂度：O(1)

## 2. 有效的字母异位词

题目：给定两个字符串，如果它们包含的字符重排后完全一样，则返回 `true`。

> https://neetcode.io/problems/is-anagram

思路 1：分别排序两个字符串，再逐位比较。

- 时间复杂度：O(n * log n)
- 空间复杂度：O(1)

思路 2：借助 `HashMap`，key 为字符，value 为出现次数。第一个字符串计数加一，第二个字符串计数减一，最后检查是否归零。

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)，字符集最多 26 个字母时可以看作常数。

思路 3：用两个长度为 26 的数组记录字符数量。字符减去 `'a'` 的 ASCII 码得到下标，下标代表字母，值代表出现次数。遍历第一个字符串时加一，遍历第二个字符串时减一，最后全部为 0 则返回 `true`。

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)

## 3. 两数之和

题目：给定数组和目标值，找出两个不同下标，使对应值相加等于目标值。题目保证答案存在。

> https://neetcode.io/problems/two-integer-sum

思路 1：借助 `HashMap`。遍历数组，用目标值减去当前值，检查差值是否已经在 map 中。如果存在，直接返回两个下标；否则把当前值和下标存入 map。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 4. 字母异位词分组

题目：给定一个字符串数组，把互为字母异位词的字符串分到同一组。

示例：

- Input: `["act","pots","tops","cat","stop","hat"]`
- Output: `[["hat"],["act","cat"],["stop","pots","tops"]]`

> https://neetcode.io/problems/anagram-groups

思路 1：遍历数组，为每个字符串计算一个字符频次 key，再用 `HashMap<key, List>` 收集。最后输出 map 的 values。

- 时间复杂度：O(n * m)，`n` 是数组长度，`m` 是最长字符串长度。
- 空间复杂度：O(n)

## 5. Top K 高频元素

题目：给定一个数组和整数 `k`，返回数组中出现频率最高的 `k` 个去重元素。

示例：

- Input: `[1,2,2,3,3,3]`, `k = 2`
- Output: `[2,3]`

> https://neetcode.io/problems/top-k-elements-in-list

思路 1：先统计频率，再按频率排序，输出频率最高的 `k` 个元素。最大堆也可以解决。

- 时间复杂度：O(n * log n)
- 空间复杂度：O(n)

思路 2：先用 `HashMap<value, count>` 统计频率，再创建 `HashMap<count, List<value>>` 按出现次数分桶。最后从 `n` 往下取值，直到取满 `k` 个元素。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 6. 字符串编码和解码

题目：给定一个 ASCII 字符串列表，设计编码方法把它变成一个字符串，再设计解码方法还原成原列表。

示例：

- Input: `["neet","code","love","you"]`
- Output: `["neet","code","love","you"]`

> https://neetcode.io/problems/string-encode-and-decode

思路 1：记录每个字符串的长度，再加分隔符。例如 `4_neet4_code`。解码时先读长度，再按长度截取后续字符串。

- 时间复杂度：O(n)，`n` 为所有字符串长度之和。
- 空间复杂度：O(1)

## 7. 除自身以外数组的乘积

题目：给定一个数组，返回一个等长数组，每个位置的值为除当前位置以外所有元素的乘积。

示例：

- Input: `[1,2,4,6]`
- Output: `[48,24,12,8]`

> https://neetcode.io/problems/products-of-array-discluding-self

思路 1：先计算所有元素乘积，再遍历数组，用总乘积除以当前值。需要单独处理数组中存在 0 的情况。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

思路 2：不使用除法。分别从前往后、从后往前遍历，记录当前索引左侧和右侧的乘积，再把两者相乘。比如从前往后可以得到 `[1, v1, v1*v2, v1*v2*v3]` 这种前缀乘积。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 8. 有效数独

题目：给定一个 `9 * 9` 数独棋盘，判断每行、每列、每个 `3 * 3` 单元格中是否都没有重复数字。

> https://neetcode.io/problems/valid-sudoku

思路 1：定义行、列、单元格三个维度的字典。关键是判断 `3 * 3` 单元格，可以用 `(row / 3, col / 3)` 作为 key，再遍历棋盘判断是否重复。

- 时间复杂度：O(n * n)
- 空间复杂度：O(n * n)

思路 2：借助数组记录状态。比如每一行用长度为 9 的数组表示，数字减 1 后对齐索引。列和单元格也类似。

- 时间复杂度：O(n * n)
- 空间复杂度：O(n)

## 9. 最长连续序列

题目：给定一个数组，找出最长连续序列的长度。数字之间差 1 即连续，不要求按原数组顺序。

示例：

- Input: `nums = [0,3,2,5,4,6,1,1]`
- Output: `7`

思路 1：先建立一个 set 存所有元素。遍历元素时，如果存在比当前元素小 1 的值，说明当前值不是连续序列起点，直接跳过；否则从当前值开始向后累加查找，记录最大长度。

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 总结

- 哈希常用于去重、计数和快速查找。
- 数组题经常围绕索引下标做文章。
- 字符和数字可以通过 ASCII 码建立映射关系。
- 前缀、后缀和前后索引经常用于优化暴力解法。
- 有些题的关键在于发现数字和索引之间的规律，比如取模或整除。
