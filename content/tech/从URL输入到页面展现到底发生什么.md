> 从URL输入到页面展现到底发生什么
<!--more-->

## 整体流程

- DNS 解析
- TCP 三次握手建立连接
- 发送 HTTP 请求
- 服务端处理请求并返回响应
- 浏览器解析并渲染页面
- 连接断开

## DNS 解析

先要把域名解析成 IP。

如果解析到了，对应的 IP 一般会进缓存。DNS 本身就是一层一层查的，常见的缓存顺序大概是：

- 浏览器缓存
- 系统缓存
- 路由器缓存
- ISP 缓存
- 根域名服务器
- 顶级域名服务器
- 权威域名服务器

## 建立连接

IP 有了之后，就要和目标机器建连接。

HTTP 走 TCP，所以这里通常会先经过三次握手，把连接建起来。

## 发送请求和返回响应

连接建好之后，浏览器就可以发 HTTP 报文了。

服务端收到请求后，会先处理业务逻辑，再把响应结果返回给浏览器。

## 浏览器渲染

浏览器拿到响应之后，会去解析 HTML、CSS、JavaScript，再把页面渲染出来。

## 连接断开

这次请求处理完之后，连接会断开，或者按 keep-alive 的方式继续复用。
